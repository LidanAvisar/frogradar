Acme launches Package Firewall 2.0

Acme today announced Package Firewall 2.0, which blocks malicious open-source packages before they reach developer machines or CI pipelines. The new version inspects npm, PyPI, Maven and Hugging Face model downloads in real time.

The firewall now uses behavioural analysis of install scripts and a reputation score for each maintainer. Policies can quarantine suspicious packages for review instead of blocking them outright, and every decision is logged with the evidence that triggered it, so security teams can audit and tune the rules.

Package Firewall 2.0 is available to Acme Enterprise customers now, and a free tier for open-source projects will follow in the first quarter. Pricing for the add-on starts at 12 dollars per developer per month.
